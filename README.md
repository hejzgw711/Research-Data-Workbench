# 生成可分析科研数据工作台

合并工作台：使用原有账号登录，在页面顶部依次切换四个工具。

- 数据反推生成：单因素 / t-test、Two-way ANOVA、重复测量时间序列，保留参数设置、候选、图表、项目打开保存及全部导出。
- WB 灰度测量：目的图与内参图配对、ROI 与泳道调整、旋转、归一化、复制和导出。
- qPCR 数据模拟：分组/重复设计、Cq 与表达量分析、96 孔板、扩增/熔解曲线，以及分析和模拟原始数据的完整下载包。入口位于 WB 和 SPR 之间。
- SPR 数据生成：动力学参数、原始与处理后曲线、表格和完整 Dataset 导出。

同一次登录期间，切换工具保留已经输入的参数、图像和结果；刷新页面仍按各工具原有方式重新初始化。退出登录后回到统一登录页。前端登录门禁与此前一致，只适合减少随意访问，不是服务端安全认证。

qPCR 使用同源独立页面嵌入，内部可滚动，深浅主题不影响其他工具。新建实验默认使用参考波动模型，旧项目仍可精确重放；导出文件明确标注模拟数据，不是仪器官方下机文件。直接访问 `/qpcr/` 也返回工作台登录/导航入口，不作为另一个免登录页面。

qPCR 参数按原有方式自动保存在当前浏览器。同一电脑的本地预览与线上网站属于不同来源，自动保存不会自动迁移；需要迁移时，在本地“保存”项目 JSON，再到线上 qPCR “打开”该文件。

浏览器本地运行的 Western Blot 灰度测量工具：上传目的条带与内参条带两张图片，框选泳道和背景后，自动测量灰度、按内参归一化，并输出分组统计与柱状图预览。所有图像像素和计算均在当前浏览器内完成，不上传任何图片。

## 本地运行

```bash
pnpm install --frozen-lockfile
pnpm dev
```

预览地址：<http://127.0.0.1:5176/>。

Windows 也可双击 `启动本地预览.cmd`，自动启动并打开网页。使用期间保留启动窗口；关闭窗口或重启电脑后，重新双击即可。已有服务运行时会直接打开页面。

验证命令：`pnpm test`（原有三个工具 27 个测试＋qPCR 60 个测试）、`pnpm build`、`pnpm test:e2e`。浏览器测试首次运行需 `pnpm exec playwright install chromium`。

生产子目录和线上验收：`node scripts/check-pages.mjs https://hejzgw711.github.io/wb-gray-studio/`。该检查在隔离浏览器中验证原有前端会话协议、四个入口、qPCR 资源及原始工作簿下载，不修改真实用户的浏览器数据。

qPCR 代码在 `src/qpcr/`，`qpcr/index.html` 与根页面由一次 Vite 构建产出，原 GitHub Pages 流程不变。qPCR 的嵌入登录检查在独立 `main.tsx`，计算与导出模块沿用已经验证的独立版本。不要将个人参考 XLS、自动保存记录或运行时目录复制到发布仓库。
